# Emburse (emburse)

Emburse is an expense management and accounts payable automation platform serving over 4 million finance leaders and business travelers worldwide. The company offers REST APIs across its product lines including Emburse Professional (formerly Certify), Emburse Spend (formerly Abacus), and Emburse Enterprise (Chrome River), enabling integrations for expense reports, corporate card management, invoice processing, receipt capture, and reimbursement workflows. The Virtual Cards API provides OAuth2-secured endpoints for creating and managing virtual and physical cards, transactions, members, and accounting data. Emburse Enterprise exposes Swagger-documented APIs for Expense, Invoice, Person, PreApproval, Purchase Order, Vendor, and Allocation resources.

## APIs

| Name | Description | Docs |
|------|-------------|------|
| Emburse Virtual Cards API | REST API for managing virtual and physical corporate cards, transactions, members, accounts, and accounting categories | [Docs](https://cards.emburse.com/api/v1/docs/) |
| Emburse Enterprise REST APIs | Swagger-documented APIs for Allocation, Expense, Invoice, Person, PreApproval, Purchase Order, and Vendor resources | [Docs](https://www.emburse.com/enterprise/implementation-toolkit/rest-api-specifications) |

| Emburse Spend API | OAuth 2.0 REST API for Emburse Spend (formerly Abacus), available to Plus plan and Partner customers | [Docs](https://help.spend.emburse.com/hc/en-us/articles/4424782291341-Emburse-Spend-API) |
